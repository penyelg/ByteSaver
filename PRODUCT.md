# ByteSaver

ByteSaver is a student-capstone marketplace for buying and selling pre-owned computer hardware and peripherals. The first release is an authenticated MVP: a single normal account can buy and sell, while admins moderate users, listings, and reports.

The auth surface should feel like a focused hardware marketplace: technical, trustworthy, efficient, and human. It should support mobile screens and make the next action obvious without looking like a generic SaaS template.
